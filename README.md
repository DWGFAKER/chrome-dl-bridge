# chrome-dl-bridge
chrome-dl-bridge 是一个轻量级、零配置的本地下载桥接扩展。它允许本机命令行工具（CLI）和各类 AI 助手 / Agent（如 Claude Code、Cursor、Paseo 等）直接调用 Chrome 原生下载引擎来下载文件。  chrome-dl-bridge is a lightweight, zero-configuration local download bridge extension. It enables command-line tools (CLI) and AI Agents/LLMs (via MCP) to leverage Chrome's native download manager to download files.
